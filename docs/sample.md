# LangChain 简介

LangChain 是一个用于开发由大语言模型 (LLM) 驱动的应用程序的框架。它提供了一套工具、组件和接口，简化了 LLM 应用的构建过程。

## 核心概念

### Chains (链)
Chain 是 LangChain 的基础构建块，将多个组件串联起来形成处理流水线。例如，将提示模板、LLM 和输出解析器组合在一起。

### Agents (代理)
Agent 是能够根据用户输入自主选择执行哪些操作的智能体。与固定的 Chain 不同，Agent 可以动态决定使用哪些工具以及使用的顺序。

### Tools (工具)
工具是 Agent 可以调用的函数，例如搜索引擎、计算器、数据库查询等。通过给 Agent 提供工具，可以扩展 LLM 的能力。

### Memory (记忆)
记忆组件允许在多次交互之间保持上下文。LangChain 提供了多种记忆类型：
- **Buffer Memory**: 保存完整的对话历史
- **Summary Memory**: 对历史进行摘要以节省 token
- **Window Memory**: 只保留最近的 K 轮对话

## RAG (检索增强生成)

RAG 是一种将外部知识注入 LLM 的技术：

1. **加载**: 从文件、网页等来源加载文档
2. **分割**: 将长文档切分为较小的块
3. **嵌入**: 将文本块转换为向量表示
4. **存储**: 将向量存入向量数据库
5. **检索**: 根据用户问题检索相关文档块
6. **生成**: 将检索结果与问题一起发送给 LLM 生成答案

## LangGraph

LangGraph 是 LangChain 团队开发的图状态机框架，特别适合构建复杂的多 Agent 系统：
- 支持循环和条件分支
- 内置状态管理
- 支持人机交互检查点
- 可视化工作流
